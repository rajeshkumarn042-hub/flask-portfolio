Flask Portfolio Website

INTRODUCTION:
This project is a simple personal portfolio website developed using Python Flask.

OBJECTIVE:
To create a basic portfolio webpage to display personal details, skills, and contact information.

TOOLS USED:
- Python
- Flask
- HTML
- CSS
- VS Code

HOW ITS WORK:
- The Flask application runs using Python.
- The HTML file inside the templates folder is loaded by Flask.
- The portfolio webpage is displayed in the browser.

FEATURES:
- Simple portfolio webpage
- About section
- Skills section
- Contact details
- User-friendly design

OUTPUT:
A working portfolio website is displayed in the browser using Flask.

CONCLUSION:
The Flask portfolio website was successfully developed and executed. This project helps in understanding basic web development using Python Flask.
